月相圖實現轉移方法

這份給要在別的專案重做同一功能的人／模型。 對過 Portfolio Tracker portfolio-tracker-v15.html（v15.947 起，現行 v15.949 仍是這套）。 月相不是自己畫的天文圖，是 TradingView 公開 Advanced Chart widget 的內建 study。

1. 它實際是什麼

觀察清單 Pro 右側技術圖走 TradingView 的 embed-widget-advanced-chart.js。 月相是 widget studies 陣列裡的一項： 

MoonPhases@tv-basicstudies

開啟後，圖上會出現月相圓點與背景區段。計算、繪圖、時間軸都由 TradingView 做，主專案不實作月相公式。

同一頁若標的改走 lightweight-charts 原生圖（加密、部分槓桿 fallback），沒有月相。 開關只在 TradingView 路徑顯示。別的專案若沒有兩套圖表引擎，可忽略這段，整頁只用 TV widget 即可。

不要做成：Canvas 自繪月亮、NASA API、或自己算朔望。PT 沒有那些程式。

2. 必守限制

  1. 公開 Advanced Chart widget 只會載入前 5 個預設 study。 第 6 個會被靜默丟掉，畫面上沒有、也不報錯。 這是 v15.947 實測後的契約，不是文件猜測。
  2. 月相開啟時，必須把 MoonPhases@tv-basicstudies 放進前五名， 並拿掉一個較不重要的 study。PT 拿掉的是 Stochastic。
  3. 建議把月相放在陣列最前面，避免再被其他 study 擠出前五。
  4. 切換開關必須拆掉舊 widget 再新建。 改 JSON 但不重掛 script，圖通常不會變。
  5. 這是 TradingView 託管元件，需能連 s3.tradingview.com 與 www.tradingview.com。離線或擋第三方腳本就沒有圖。
開關studies（剛好 5 個）
關（預設） MASimple@tv-basicstudies、STD;Linear_Regression、STD;Stochastic、STD;MACD、STD;RSI
開 MoonPhases@tv-basicstudies、MASimple@tv-basicstudies、STD;Linear_Regression、STD;MACD、STD;RSI（無 Stoch）

Study 字串有兩種寫法，PT 混用且已上線可用： Name@tv-basicstudies（MA、月相）與 STD;Name（LinReg、Stoch、MACD、RSI）。 轉移時請原樣複製，不要自行統一改名。

3. 最小實作步驟

  1. 頁面上準備一個固定高度的容器（PT 約 640px 高）。
  2. 用 JS 建立 div.tradingview-widget-container，裡面再放 div.tradingview-widget-container__widget。
  3. 再建 script，src 設為 https://s3.tradingview.com/external-embedding/embed-widget-advanced-chart.js， async，script 的 textContent 是一份 JSON 字串（不是外部 json 檔）。
  4. JSON 裡帶 symbol、interval、theme、studies。
  5. 加一個 checkbox。開啟 → studies 換成含月相的 5 個；關閉 → 恢復不含月相的 5 個；然後清空容器重跑 2–4。
  6. 偏好可寫 localStorage。PT 的 key 是 pt_watchlist_moon_phases_v1，值 '1'／沒有或其它都當關。這是 UI 偏好，不要同步到雲端。

4. 可直接貼的核心碼

下面是從 _renderWatchlistTradingView 抽出的最小形狀。把 container 換成你的 DOM 節點，tvSymbol 換成 NASDAQ:AAPL 這種交易所前綴代碼。

function moonStudies(enabled) {
  return enabled
    ? [
        'MoonPhases@tv-basicstudies',
        'MASimple@tv-basicstudies',
        'STD;Linear_Regression',
        'STD;MACD',
        'STD;RSI'
      ]
    : [
        'MASimple@tv-basicstudies',
        'STD;Linear_Regression',
        'STD;Stochastic',
        'STD;MACD',
        'STD;RSI'
      ];
}

function mountAdvancedChart(container, tvSymbol, moonOn) {
  container.innerHTML = '';
  const wrap = document.createElement('div');
  wrap.className = 'tradingview-widget-container';
  wrap.style.cssText = 'height:100%;width:100%';
  const widget = document.createElement('div');
  widget.className = 'tradingview-widget-container__widget';
  widget.style.cssText = 'height:100%;width:100%';
  const script = document.createElement('script');
  script.src = 'https://s3.tradingview.com/external-embedding/embed-widget-advanced-chart.js';
  script.async = true;
  script.text = JSON.stringify({
    autosize: true,
    symbol: tvSymbol,
    interval: 'D',
    timezone: 'Asia/Taipei',
    theme: 'dark',
    style: '1',
    locale: 'zh_TW',
    allow_symbol_change: true,
    calendar: false,
    hide_side_toolbar: false,
    support_host: 'https://www.tradingview.com',
    studies: moonStudies(moonOn)
  });
  wrap.appendChild(widget);
  wrap.appendChild(script);
  container.appendChild(wrap);
}

切換月相或換標的時：先把「已渲染 key」清掉（PT 用 `${tvSymbol}|moon:${on ? '1' : '0'}`）， 再呼叫 mountAdvancedChart。 key 沒變且容器裡還有 .tradingview-widget-container__widget 就不要重掛，避免閃爍。

其它 widget 欄位（timezone、locale、theme）可依新專案改，與月相能否出現無關。月相只取決於 studies 前五名有沒有 MoonPhases@tv-basicstudies。

5. UI 與記憶

PT 的開關是圖表標題列右側的 label + checkbox：

<label class="watchlist-moon-toggle" title="顯示或隱藏月相">
  <input type="checkbox" onchange="setWatchlistMoonPhasesEnabled(this.checked)">
  <span>月相</span>
</label>
  • 開啟時副標改成「MA / LinReg / MACD / RSI / 月相」。
  • 關閉時副標是「MA / LinReg / Stoch / MACD / RSI」。
  • setWatchlistMoonPhasesEnabled：寫記憶體旗標 → 寫 localStorage → 清 render key → 整張圖重畫。
  • 啟動時讀 localStorage.getItem('pt_watchlist_moon_phases_v1') === '1'。新專案請換成自己的 key，不要沿用這個字串，以免跟 PT 同網域時搶值。

6. 何時不要顯示月相

PT 的 _updateWatchlistMoonControl(mode)：

  • mode === 'tv'：顯示開關，checkbox 可用。
  • 未選標的、沒有 tvSymbol、或走原生圖：display:none，並 disabled。

原因：原生圖沒有 MoonPhases study。開關開著卻沒有月相，使用者會以為壞了。

7. 不要從 PT 一起帶走的東西

月相只碰觀察清單的視覺圖。下面這些與月相無關，別專案不該為了月相去抄：

  • 持倉、close pair、今日損益、Gist、userDataHash、pending。
  • 觀察清單報價、_watchlistQuotes。
  • lightweight-charts 的 MA／LinReg／RSI 自繪（那是原生圖 fallback，沒有月相）。

PT 註解寫死：TradingView 僅 visual-only，不寫報價與損益。新專案也應把月相當成裝飾層。

8. 驗收清單

  1. 開關關閉：圖上有 MA、LinReg、Stoch、MACD、RSI，沒有月相圓點／背景區段。
  2. 開關開啟：出現月相；Stoch 消失；仍有 MA、LinReg、MACD、RSI。
  3. 陣列不要超過 5 個。第 6 個加月相會看起來「點了沒反應」。
  4. 切換開關後圖會重建（短暫空白再出現是正常的）。
  5. 重新整理後開關狀態與上次一致（若有做 localStorage）。
  6. 未選標的時不要露出不能用的月相開關。
  7. Network 裡看得到 embed-widget-advanced-chart.js；擋廣告／擋 TV 時應有降級說明，不要當自己的 bug。
一句話交給實作模型：用 TradingView Advanced Chart widget，studies 最多 5 個； 要月相就把 MoonPhases@tv-basicstudies 放第一位，並拿掉 Stoch；改開關就拆掉舊 widget 重建。
